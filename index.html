Tema 02

De fora × de dentro

Pressão de fora

O vendedor empurra.

→ o cliente se defende.

Pressão de dentro

O cliente percebe sozinho.

→ o cliente decide.

2 cliques. Clique 1: pressão de fora (o vendedor empurra, o cliente se fecha). Clique 2: pressão de dentro (o cliente percebe que precisa mudar). O método inteiro trabalha a pressão de dentro.
